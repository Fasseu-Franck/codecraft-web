**Question 1**
```
Q : À qui s'adresse Codecraft ?

R : Codecraft s'adresse à tous ceux qui souhaitent apprendre à coder de manière 
pratique et collaborative :
• Débutants complets en reconversion professionnelle
• Étudiants qui veulent compléter leurs cours théoriques
• Développeurs juniors cherchant à consolider leurs bases
• Centres de formation souhaitant moderniser leur pédagogie

Que vous ayez 0 ou plusieurs années d'expérience, nos parcours s'adaptent 
à votre niveau.
```

---

**Question 2**
```
Q : Comment fonctionnent les parcours de formation ?

R : Chaque parcours est structuré en projets progressifs qui couvrent une 
compétence ou une technologie spécifique (HTML/CSS, JavaScript, React, etc.).

Pour chaque projet :
1. Vous consultez les instructions et objectifs pédagogiques
2. Vous codez directement dans l'éditeur intégré
3. Vous voyez le résultat en temps réel dans la zone de prévisualisation
4. Vous échangez avec la communauté en cas de blocage
5. Vous validez le projet et passez au suivant

Les projets sont conçus pour construire vos compétences étape par étape, 
du plus simple au plus complexe.
```

---

**Question 3**
```
Q : Est-ce adapté aux débutants complets ?

R : Absolument ! Codecraft a été conçu dès le départ pour les débutants.

Nos parcours "Fondamentaux" commencent par les bases absolues :
• Qu'est-ce que le HTML ? Comment fonctionne le web ?
• Votre première page web en 15 minutes

L'environnement de code intégré évite la complexité de l'installation d'outils. 
Vous commencez à coder en un clic, sans configuration. Et la communauté est 
là pour répondre à toutes vos questions, même les plus basiques.

Des milliers de débutants ont fait leurs premiers pas avec Codecraft.
```

## 📝 Notes de style et de ton

### Principes rédactionnels appliqués

1. **Clarté** : Phrases courtes, vocabulaire accessible, concepts expliqués simplement
2. **Valeur** : Focus sur les bénéfices utilisateurs, pas sur les features techniques
3. **Preuve** : Chiffres, témoignages, garanties pour rassurer
4. **Action** : CTAs clairs et répétés aux moments stratégiques
5. **Inclusivité** : Langage qui s'adresse à tous les niveaux sans condescendance

### Ton de voix Codecraft

- **Professionnel mais accessible** : Expert sans être prétentieux
- **Encourageant** : Met en confiance, positif, orienté réussite
- **Moderne** : Vocabulaire startup tech, langage actuel
- **Transparent** : Honnête sur les défis, clair sur les solutions
- **Bienveillant** : Empathique face aux difficultés d'apprentissage
